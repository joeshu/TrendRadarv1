# TrendRadar 全页面视觉审计基线

## 参考输入
- 用户附件：设置、报告、热榜、发现四页真实设备截图。
- 生图技能参考板：`generated-reference/`，只用于结构、密度、层级和视觉方向，不复制虚构数据。
- 产品能力底稿：`product-capability-brief.md`。

## 已确认的统一视觉语言
- 冷白背景：接近 iOS 原生纸张白，不使用明显渐变噪声。
- 卡片：白色圆角卡片，1px 淡彩边框，轻阴影；卡片之间留白稳定。
- 主色：电光蓝；状态色：绿=正常、琥珀=部分异常、品红=收藏/报告、靛紫=分析。
- 字体：中文系统无衬线；标题 semibold；数字 bold；辅助文字 regular；英文眉标题少量字距。
- 顶部：系统导航标题居中；右侧操作使用圆形浅色按钮。
- 底部：五项 Tab，半透明但不能模糊或遮挡内容；滚动内容必须有安全底部内边距。
- 数据：只使用真实 Store 数据，参考图的数字不进入产品。

## 页面逐页检查点
### 总览
Hero → 信息源状态 → 四项指标 → 快速操作 → 实时热点 → 最新情报；检查首屏密度和底部遮挡。

### 发现
发现中心头部 → 订阅/洞察切换 → 搜索 → 来源胶囊 → 统计卡 → 情报列表；检查英文标题、来源标签和未读/收藏状态。

### 热榜
热榜雷达头部 → 三项统计 → 雷达状态卡 → 平台胶囊 → 主题排名卡；检查排名、平台来源、趋势色和刷新状态。

### 报告
本地情报档案头部 → 三项统计 → 搜索/筛选 → 报告历史；检查生成入口、状态、日期、条数、耗时和导出动作。

### 设置
配置中心摘要 → 设置分类入口；检查标题层级、每行高度、图标色、辅助文字和保存反馈。

## 实施顺序
1. 公共组件和导航安全区
2. 发现页
3. 热榜页
4. 报告页
5. 设置页及展示子页
6. 其他详情/管理页

每一页修改后运行 `git diff --check`、Swift CI 和 IPA 构建；不将生图参考板中的虚构内容写入业务逻辑。
